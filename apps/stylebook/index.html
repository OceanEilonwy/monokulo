Component library · 0.1

One shared language.

Native HTML foundations. Progressive enhancement. The same components from signup to the counter.

Use your browser’s JavaScript setting to review the native fallbacks. Every example and its HTML contract are present before scripts run.

Foundations

One palette, spacing scale and type system across every surface.

Use semantic tokens from @monokulo/ui/tokens.css. Theme defaults to the system preference.

HTML contract

Layout & headers

Containers, stacks and grids own the spacing between components.

Use semantic headings in order. Panels carry no application behaviour; grid columns collapse to fit the available space.

HTML contract

Buttons

Native buttons and links, with explicit intent and size variants.

data-variant="primary|danger|quiet"; default is secondary. data-size="compact|touch"; data-block fills the width. Use native disabled while an action is unavailable.

HTML contract

Fields & validation

Labels, descriptions and errors remain associated with native controls.

Validation belongs to the application. Render aria-invalid and connect hint/error IDs through aria-describedby. Keep server validation even when client validation is enabled.

HTML contract

Enhanced select

The original select remains the form field. Keyboard selection, form reset and programmatic changes use the same value.

Set the nested select’s value; listen to its native change event. Without JavaScript this is a standard select and GET form. The programmatic demonstration requires JavaScript.

HTML contract

Switch

An ordinary checkbox with a visual on/off track.

The checkbox supplies keyboard and form behaviour with or without JavaScript. Unchecked checkboxes are absent from submitted form data.

HTML contract

Details & disclosures

Structured facts and native disclosure behaviour need no JavaScript.

Use dl/dt/dd for facts and details/summary for disclosure. The browser owns opening, closing and keyboard behaviour.

HTML contract

Feedback

Visible words communicate status as well as colour.

Use role="status" for dynamically updated information and role="alert" for urgent errors. Static examples do not need live announcements.

HTML contract

Breadcrumbs & back links

Real links describe where you are and where you can return.

Use an ordered list for a full breadcrumb trail, explicit separators with aria-hidden="true", and aria-current="page" for the current page. Back links have a real href; they never depend on browser history. Long ancestor names truncate visually and retain their full accessible name.

HTML contract

Steps & segments

Flat progress strips show completed tasks. Wallet fills one-third after Kind and two-thirds after Back up; upcoming stages remain empty.

Use .mk-progress-steps with data-design="strip". Each native progress element has explicit value, max and an accessible label. Include the active task and its position inside the top-level segment label; the bar measures completed tasks.

HTML contract

Action cards

Choices with a heading, explanation and one explicit action.

Use a section with a named heading and a native link or button. data-recommended and data-unavailable style the state; include its meaning in visible text. Unavailable actions must use a real disabled button. The card itself is not a second click target. This example submits only a local GET form.

HTML contract

Typography

One type scale: headings use 1.2 line height; body and supporting text use 1.5. Classes express visual hierarchy independently of heading semantics.

HTML contract

Spacing

Use the shared tokens for padding and gaps. Orange measures space; the nested example shows panel padding and stack rhythm.

HTML contract

Status text & chips

Plain text is the default. Use a chip only when its boundary helps identify a category or an interactive selection.

Use .mk-status-text for descriptive state. Place it alongside the title it qualifies. Reserve space for settings change counts so edits never move the layout. Status must be understandable from its wording, not color alone.

Network badges

Mainnet has a solid edge and coin icon. Test networks use a dashed edge and flask. Always include the network name.

HTML contract

Icons in buttons

Decorative SVGs are hidden from assistive technology. Icon-only buttons require an accessible name and a 44px target.

HTML contract

Icon set

Canonical 24 × 24 SVGs live in @monokulo/ui/icons/*.svg. Inline them to inherit currentColor; no icon font or JavaScript is required.

HTML contract

Page forms & save bar

The existing settings component: edit the store name to review changed fields, card highlighting, discard and the save bar. This GET demo reloads the stylebook; it does not persist settings. Production forms POST to the application. Import @monokulo/ui/settings once per page; one settings form per page.

HTML contract

Toasts

Status messages use opaque backgrounds and a uniform thin border. Review examples stay visible. Applications own placement, live announcements and dismissal timing. Errors should remain until resolved or dismissed.

HTML contract

Navigation & user menu

Navigation uses real links and wraps on narrow screens. The user dropdown is native details: Tab navigates its links; JavaScript adds outside-click and Escape dismissal. These are navigation links, not ARIA menu widgets.

HTML contract

Tabs

Page tabs are links with aria-current. In-page tabs upgrade anchors and visible sections into a keyboard tablist: Left/Right, Home and End. Applications such as POS may drive the same classes and ARIA states themselves.

HTML contract

Progress & spinner

Use visible status text alongside the decorative spinner. Reduced-motion preference stops rotation. Native progress covers measurable work.

HTML contract

Inputs with actions

A native field and a separate named button. Search submits without JavaScript. Enable camera scanning only when the application can provide it.

Ellipsis & copy

The complete value is in the DOM, accessible and selectable without JavaScript. CSS ellipsis never modifies the copied value. The enhanced copy button reports clipboard permission failures and selects the text for manual copying.

QR code
