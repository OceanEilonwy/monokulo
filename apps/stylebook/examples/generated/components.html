Button

A button for an action on the page. One that goes somewhere is a LinkButton: a link, not a button.

Props
PropTypeAbout
childrenSlotRequired. What it says: the action, as a verb ("Save", "Delete store").
variantOption<ButtonVariant (primary | danger | quiet)>How much a button stands out. Without one it is secondary: most buttons are, and a page has at most one primary.
sizeOption<ControlSize (compact | touch)>A control's size. Without one it is the normal size.
kindButtonType (button | submit | reset)Defaults to button, so it never submits a form by accident. Default: button.
blockboolFills its container's width. Default: false.
disabledboolDefault: false.
busyboolMarks it working (a save in flight): the cursor shows progress. Default: false.
restAttrs

Select

The site's one dropdown. The page sends an ordinary select: without JavaScript it is all there is, and each option's text says everything. Once its island attaches, a button and a list that floats over the page draw the options' parts, with search, type-ahead and the keys a listbox takes; the select stays the field, so forms, required, fixi and other scripts that read it keep working.

Props
PropTypeAbout
nameStringRequired. The form field's name.
optionsVec<Choice>Required. One option of a [Select]. Its text says everything in words, for a browser without JavaScript (Label (detail) [Network] [chip] - note); the enhanced list draws the same parts on their own: a logo, a label, a monospace detail, a network badge, a chip, a note.
idOption<String>
labelOption<String>The accessible name, for a select with no <label>.
compactboolThe toolbar size. Default: false.
searchSearchMode (auto | show | hide)Whether the list has a find box. Default: auto.
requiredboolDefault: false.
disabledboolDefault: false.
restAttrsMore attributes on the select: aria-describedby, data-saved, fx-*.
