Button

A button for an action on the page. One that goes somewhere is a `LinkButton`: a link, not a button.

Props
PropTypeAbout
childrenSlotRequired. What it says: the action, as a verb ("Save", "Delete store").
variantOption<ButtonVariant (primary | danger | quiet)>
sizeOption<ControlSize (compact | touch)>
kindButtonType (button | submit | reset)Defaults to `button`, so it never submits a form by accident. Default: button.
blockboolFills its container's width. Default: false.
disabledboolDefault: false.
busyboolMarks it working (a save in flight): the cursor shows progress. Default: false.
restAttrs

Field

A labelled text input, with what it's for and what's wrong with it tied to it for screen readers. The label is required: an input never goes without one.

Props
PropTypeAbout
labelStringRequired. What the input is ("Email").
idStringRequired. The input's id: the label, hint and error point at it.
nameStringRequired. The form field's name.
kindInputType (text | email | password | number | url | search | tel)Default: text.
valueOption<String>
placeholderOption<String>
autocompleteOption<String>
hintOption<String>What it's for, under the input.
errorOption<String>What's wrong with what was entered. Marks the input invalid.
requiredboolDefault: false.
readonlyboolDefault: false.
disabledboolDefault: false.
sizeOption<ControlSize (compact | touch)>
restAttrsMore attributes on the input: `minlength`, `inputmode`, `fx-*`.
