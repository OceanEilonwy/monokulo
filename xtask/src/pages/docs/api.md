# HTTP API

Monokulo's HTTP API lets your server, a shop plugin or an app make orders
and follow them without the JS library: `/api/v1` on your Monokulo's own
address.

The reference is coming: every resource, its links and forms, the link
relations (`/rels/`) and the problems it answers with (`/problems/`), with
the OpenAPI document beside them.

Until then, see [Shop plugins](../plugins/) for how a server makes an order
with the store's secret key, and [Webhooks](../webhooks/) for what Monokulo
sends back.
