Checkout: the paid state

Today a paid order inserts a “Paid” box above everything, repeats it in a “PAID” tag, keeps the QR code up (inviting a second payment), reads “101 / 1 confirmations” and appends a payments table: the whole page jumps. Each option below keeps the awaiting card's footprint when it turns paid. The dashed orange line marks where the payment block ends: it does not move.

  • Only an error (underpaid, overpaid, double spend) may grow the page, with a message the customer has to read.
  • All options also: confirmations read as “Confirmed” instead of “101 / 1”; no raw timestamps; the payment is listed by a short transaction id in the space the address used; the refund section stays where it was.
